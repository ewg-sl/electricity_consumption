# Прогнозирование потребления электроэнергии (Energy Consumption Forecasting)

## Цель проекта
Разработка и сравнение моделей машинного обучения для прогнозирования почасового потребления электроэнергии на горизонте до 24 часов. Задача регрессии, данные — временной ряд с суточной и недельной сезонностью.

## Данные
*   **Источник**: [UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/321/electricityloaddiagrams2011).
*   **Признаки**: Лаги (lag_1…lag_24), разности (diff_1), скользящие средние, календарные признаки (час, день недели, месяц).
*   **Целевая переменная**: `total_cons` (общее потребление).
*   **Разбиение**: Хронологическое (train: 2011–2013, test: 2014).

## Методология
*   **Валидация**: `TimeSeriesSplit` (5 фолдов) для исключения утечки данных.
*   **Модели**: DummyRegressor (baseline), ElasticNet, RandomForest, XGBoost.
*   **Подбор гиперпараметров**: GridSearchCV.
*   **Проверка утечек**: Сдвиговый тест (RMSE при сдвинутой цели вырос в 5.9 раз), анализ корреляций лагов.

## Результаты
| Модель | Test RMSE | Test MAPE | CV RMSE (mean ± std) |
|--------|-----------|-----------|----------------------|
| **XGBoost** | **3876.60** | **1.57 %** | 15322.5 ± 14977.8 |
| ElasticNet | 5097.92 | 2.04 % | 4501.6 ± 1216.2 |
| RandomForest | 6094.55 | 2.50 % | 15053.8 ± 14539.0 |
| Dummy (baseline) | 85272.73 | 35.42 % | 88039.8 ± 38690.2 |

**Лучшая модель**: XGBoost (RMSE 3877, MAPE 1.57 %). Важность признаков (gain, permutation, SHAP) показала доминирование `lag_24`, `lag_1` и `diff_1`.

## Ограничения модели
*   Не учитывает внешние факторы (погода, праздники, экономические кризисы).
*   Зависит от качества исторических данных; резкие изменения структуры потребления требуют переобучения.
*   Горизонт прогноза ограничен 24 часами; при больших горизонтах ошибки лагов накапливаются.
*   Не различает новых клиентов (требуется явное добавление фичей или переобучение).
